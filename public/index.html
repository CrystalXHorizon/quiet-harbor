 现实中的支持

此刻，不必一个人承担。

如果你可能马上伤害自己或他人，或已经受伤、服药过量，请立即联系当地急救服务或前往急诊，并请身边可信任的人陪着你。

在能安全做到的情况下，先远离可能伤害自己的物品。这里不会自动报警，也没有真人实时查看聊天。

可以向信任的人这样开口：
“我现在状态不太好，希望你能陪我一会儿，帮我一起联系支持。”

持续的游离感、记忆困扰或身份相关体验，适合与有相关经验的精神科医生或心理治疗师讨论。

账户与隐私

登录后，由站点后台提供 AI 服务，无需填写个人 API Key。发送的聊天会经过后台和所选 AI 服务商，站点不保存聊天正文；服务商可能按其政策保留请求。

私人聊天与社区帖子相互独立。只有你主动发布的内容会进入社区。退出账户或刷新页面会清空本页聊天。

旧版在此设备保存的加密 API Key 不会被新版读取或上传。你可以删除旧副本。

 陪伴保护机制 · HARNESS

支持你的感受，尊重你的选择。

留岸是情绪支持工具，不是治疗师，不诊断解离性身份障碍，不承诺治愈。

  1. 先确认边界输入检查与 AI 风险判断，优先回应当下安全。
  2. 让对话保持稳妥固定陪伴规则、有限上下文；不催眠、不恢复记忆、不诱导身份切换。
  3. 回答前再检查回答通过规则与独立检查后才显示。检查失败会暂停 AI 回复。
  4. 隐私留有选择应用不把聊天写入数据库、浏览器存储或日志。AI 服务商可能按其政策保留请求。

联网对话的 Harness 在后端执行，先验证账户、额度和权限，再调用 AI。这些保护可能误判或漏判，尚未经临床验证。体验模式只有本地规则与预设文字。你可以随时寻求现实中的支持。
