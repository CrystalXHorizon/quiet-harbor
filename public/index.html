连接 AI 模型

选择供应商，填写模型与密钥。使用浏览器直接连接；支持情况取决于模型权限和供应商的跨域设置。

供应商官方接入文档 ↗预设地址可按账户地区修改。支持 Base URL 或完整的 chat/completions、messages 地址；不支持仅提供 Responses、云签名或网页登录的接口。默认仅在当前页面保留。可选择在此设备加密保存；不会上传到 GitHub。断开仅清除当前已解锁密钥，不删除加密副本。

连接测试会发送一条不含聊天内容的短请求，可能计费；正常聊天通常产生三次请求。切换并连接成功后会清空当前聊天，避免将之前的对话发给另一供应商。

先填写 API Key 并同意发送。列表包含账户返回的模型，并非全部适用于聊天；火山方舟也可填写接入点 ID。读取失败时仍可手动填写。
兼容性选项关闭此选项仍会要求并严格检查 JSON 结果，不会取消陪伴保护机制。建议使用能遵循指令的文本对话模型。

设置解锁密码后保存；已有连接时输入密码解锁，自动恢复供应商、地址与模型。只保存一份连接，替换会覆盖旧副本。密码不会保存或发送。刷新后需重新解锁。加密保护设备中的存储，不能防止解锁后页面脚本访问密钥。

 陪伴保护机制 · HARNESS

支持你的感受，尊重你的选择。

留岸是情绪支持工具，不是治疗师，不诊断解离性身份障碍，不承诺治愈。

  1. 先确认边界输入检查与 AI 风险判断，优先回应当下安全。
  2. 让对话保持稳妥固定陪伴规则、有限上下文；不催眠、不恢复记忆、不诱导身份切换。
  3. 回答前再检查回答通过规则与独立检查后才显示。检查失败会暂停 AI 回复。
  4. 隐私留有选择应用不把聊天写入数据库、浏览器存储或日志。AI 服务商可能按其政策保留请求。

Harness 在浏览器中执行，并非不可绕过的服务端防护。这些保护可能误判或漏判，尚未经临床验证。体验模式只有本地规则与预设文字。你可以随时寻求现实中的支持。
