连接 DeepSeek

直接连接 DeepSeek 官方 API，不需要部署服务端。连接后，聊天内容及最近部分对话会直接发送给 DeepSeek。

默认仅在当前页面保留。可选择在此设备加密保存；不会上传到 GitHub。断开仅清除当前已解锁密钥，不删除加密副本。

接口已配置为 DeepSeek 官方地址。每轮通常包含三次 API 请求：输入检查、回复生成和输出检查，按你的 DeepSeek 账户计费。

设置解锁密码后保存；已有密钥时输入密码解锁。密码不会保存或发送。刷新后需重新解锁。加密保护设备中的存储，不能防止解锁后页面脚本访问密钥。

 陪伴保护机制 · HARNESS

支持你的感受，尊重你的选择。

留岸是情绪支持工具，不是治疗师，不诊断解离性身份障碍，不承诺治愈。

  1. 先确认边界输入检查与 AI 风险判断，优先回应当下安全。
  2. 让对话保持稳妥固定陪伴规则、有限上下文；不催眠、不恢复记忆、不诱导身份切换。
  3. 回答前再检查回答通过规则与独立检查后才显示。检查失败会暂停 AI 回复。
  4. 隐私留有选择应用不把聊天写入数据库、浏览器存储或日志。AI 服务商可能按其政策保留请求。

Harness 在浏览器中执行，并非不可绕过的服务端防护。这些保护可能误判或漏判，尚未经临床验证。体验模式只有本地规则与预设文字。你可以随时寻求现实中的支持。
